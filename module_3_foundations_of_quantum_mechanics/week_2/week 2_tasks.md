### Problem 1
Using the axioms for inner products:
1. linearity: $\langle C | \{ | A \rangle + | B \rangle \} = \langle C | A \rangle + \langle C | B \rangle$;
2. interchanging bras and kets corresponds to complex conjugation: $\langle B | A \rangle = \langle A | B \rangle^*$,

1. prove $\{ \langle A | + \langle B | \} | C \rangle = \langle A | C \rangle + \langle B | C \rangle$,
2. prove $\langle A | A \rangle$ is a real number.

---

### Problem 2
1. Suppose that $f(x)$ and $g(x)$ are two eigenfunctions of an operator $\hat{Q}$ with the same eigenvalue $q$. Show that any linear combination of $f$ and $g$ is itself an eigenfunction of $\hat{Q}$ with eigenvalue $q$.
2. Check that $f(x) = \exp(x)$ and $g(x) = \exp(-x)$ are eigenfunctions of the operator $\mathrm{d}^2/\mathrm{d}x^2$, with the same eigenvalue. Construct two linear combinations of $f$ and $g$ that are orthogonal eigenfunctions on the interval $(-1, 1)$.

---

### Problem 3
Which of the following functions make good wave functions for describing a particle moving in one dimension? Sketch the probability density for each of them and check whether it is normalisable. Determine the normalisation constant $C_n$ for those that are normalisable. (The parameters $\lambda_n$ are all *real* and *positive*).

a. $\psi_1(x) = \begin{cases} 0 & \text{for } x < 0, \\ C_1 \sin(\lambda_1 x) & \text{for } 0 \le x \le 2\pi/\lambda_1, \\ 0 & \text{for } x > 2\pi/\lambda_1. \end{cases}$

b. $\psi_2(x) = C_2 \frac{1}{x + \lambda_2}$ for all $x$.

c. $\psi_3(x) = C_3 \exp(\lambda_3 x^2)$ for all $x$.

d. $\psi_4(x) = C_4 \exp(-\lambda_4 |x|)$ for all $x$.
