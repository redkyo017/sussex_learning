# Assessment 1 (PRB): what to type into each Canvas box

You upload `QT_PRB_solutions.pdf` at **Question 12**. Canvas also shows a text box for each of Questions 1–11. Paste one **pointer line** into each box.

A pointer line tells the marker where that question's solution is. Canvas markers grade question by question, so an empty box shows as "No response" before they ever reach the PDF at Q12. The pointer prevents that.

Pointer only, no answers in the boxes: all workings and answers live in the PDF, so a box can never contradict it. The PDF uses the same numbering as Canvas, and page 13 has a summary table of every result.

**How to do it.**
- Open the quiz in **one browser tab only**. Canvas warns that a second tab can auto-save over your work.
- Paste the lines as plain text.
- Upload the PDF at Q12, check it shows as attached, then press **Submit**.
